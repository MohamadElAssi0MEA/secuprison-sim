# SecuPrison Simulation

This repository contains a browser-based simulation visualizing one vulnerability per OSI layer using a prison analogy.

- `frontend/` — React + D3 app that runs entirely in the browser and can be deployed to GitHub Pages.
- `backend/` — optional Node.js demo API for local/expert labs (Docker-compose ready).

## Quickstart (frontend)
cd frontend
npm install
npm run start

## Deploy to GitHub Pages
Follow steps below or use the provided GitHub Action.

See .github/workflows/pages-deploy.yml for CI deploy.

## Educational modes
- Learner Mode: guided simulation + basic evaluation saved to localStorage
- Operator Mode: detailed logs and technical metrics
